# 第一轮：会话可靠性、输入释放与桌面生命周期

本机验证于 2026-11-13 完成。

## 使用与升级

两台电脑必须同步升级到协议 v2。默认基础端口为 4242，允许范围为 1…65534：

| 通道 | 服务端监听端口 | 用途 |
| --- | --- | --- |
| UDP | P | 控制端计算的绝对鼠标位置 |
| TCP（TCP_NODELAY） | P | 握手、心跳、按钮、滚轮、键盘、控制权及设置 |
| TCP | P+1 | 当前会话绑定的双向文本剪贴板 |

旧 UDP 协议只用于识别和提示升级，不进入新端的输入抑制流程。旧版客户端无法与新版服务端共享输入。地址目前使用数字 IP 和端口；服务端监听 IPv4。连接没有新增身份认证或加密，仍限可信局域网。

CLI 与 GUI 共用 `SessionConfig`、`SessionCommand`、`SessionSnapshot`、`SessionHandle`。CLI 新增 `--no-keyboard`、`--no-clipboard`、`--no-reconnect`、`--debug`；Ctrl+C 和终止信号请求同一取消流程。

## 会话与输入

- 统一状态：待机、监听、连接中、已连接、重连中、停止中、失败。输入归属独立记录，界面和托盘读取同一快照。
- 控制连接每秒发送心跳；单调时钟计算 5 秒有效对端消息超时，TCP 断开立即处理。UDP 移动不刷新可靠通道存活时间；静止超过 5 秒也不会失去控制。
- 客户端按 1、2、4、8 秒重试，此后上限 8 秒，附加 0…149ms 抖动；成功后重置。主动停止、取消、退出或关闭自动重连可取消等待。
- 同设备新连接替换整个旧会话，包括实际 UDP 目标地址、屏幕、功能配置和输入状态；其他设备收到忙碌原因。
- TCP 控制帧为 4 字节大端长度前缀加 bincode 消息。会话随机标识、控制权代次、控制序号及移动序号用于隔离过期输入。非当前会话的 TCP/UDP 消息直接忽略。
- UDP 使用绝对位置，旧序号和重复移动不会回退光标。离散输入携带对应位置；先定位后执行点击，跨通道移动等待对应控制序号。保留按显示刷新率合并光标移动的机制。
- `PressedInputState` 只记录本会话成功注入的输入。离开、断线、停止、会话替换、错误返回及线程展开都释放按钮、键和修饰键；重复清理不重复成功的释放，释放错误逐项记录并继续处理。
- 鼠标、键盘抑制独立。关闭键盘转发先释放远端按键，确认后恢复本地键盘；远端归属按键的后续松开事件不会成为本地孤立松开。
- 捕获到的按住状态和进入远端前的系统物理状态都参与判断；仍有按键或按钮按住时暂缓跨屏。本轮不支持按住跨屏拖拽。
- macOS 修饰键依据左右键独立标志识别；Caps Lock 单独处理。Windows 检查实际 `SendInput` 注入数量。
- 捕获队列满、捕获线程错误或可靠控制积压会结束故障会话并恢复本地控制。离散事件不被静默丢弃。

## 设置与桌面行为

配置为版本 1 JSON，含设备标识、语言、端口、方向、功能选项、成功角色及最后成功会话的参数。保存采用同目录临时文件、同步及原子替换；损坏文件先改名为 `config.corrupt-*.json`，再提示恢复默认。

- macOS：`~/Library/Application Support/com.xunfei.mouse-share/config.json`
- Windows：`%APPDATA%\MouseShare\config.json`
- 测试隔离：`MOUSE_SHARE_CONFIG_DIR`，不改变系统登录启动项位置。

| 设置 | 生效方式 |
| --- | --- |
| 键盘转发 | 会话内协商，关闭后释放按键；只允许同系统键码。两端均显示跨系统不兼容原因 |
| 剪贴板同步 | 协商后启停双向读取、发送和应用；重新开启使用新 epoch，废弃旧连接和未完成数据 |
| 断线自动重连 | 控制故障重试；关闭时取消待执行退避，不覆盖主动停止 |
| 默认端口、方向 | 保存用于下一次手动启动，不重启当前会话；被控端显示控制端协商的方向 |
| 调试日志 | 动态修改等级；默认关闭详细输入日志，不记录剪贴板正文；输出移至日志线程 |
| 语言 | 即时切换并持久保存 |
| 开机启动 | 默认关闭，必须主动启用；注册失败或配置写入失败回退并显示错误 |
| 菜单栏／托盘 | 默认开启，在 UI 主线程即时创建或移除；移除前恢复窗口 |

登录启动通过 `--autostart` 恢复最后成功运行的角色和连接参数，使用当前的功能设置；普通启动展示窗口并恢复保存的编辑配置。未成功的连接编辑不会替换成功会话记录。开启托盘时关窗隐藏并继续共享，菜单提供打开、启动、停止和退出；关闭托盘后关窗退出。GUI 单实例锁配合本地唤醒通道避免重复捕获和占用端口。

macOS 注册当前用户的 LaunchAgent，保留应用 macOS 11 部署目标；Windows 注册 HKCU Run，不改系统级配置。依据：[Apple LaunchAgent](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html)、[Microsoft Run](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。托盘遵守 [tray-icon 主线程和事件唤醒约束](https://docs.rs/tray-icon/0.26.1/tray_icon/)。

## 停止与剪贴板

停止按钮只发取消命令并同步更新“停止中”，UI 仅 `join()` 已完成线程。后台先恢复本地控制和释放远端输入，再关闭网络、取消退避、回收工作线程；退出期间仍处理窗口事件。托盘退出、无托盘关窗和终止信号共用该流程。

TCP 连接、部分帧读取、写入及重试等待均为非阻塞／短间隔可取消流程。剪贴板使用单个双向工作线程，任一方向 EOF 或错误会结束整个连接，不再出现收发线程互相 `join()`。每次重新开启重新绑定会话和 epoch；旧连接、半包和旧 epoch 不会在开启后写入剪贴板。输入控制与大文本传输使用不同 TCP 连接。

## 验证记录

本机使用真实 loopback TCP/UDP 与模拟捕获／注入／剪贴板设备执行回归，不向真实桌面注入测试键鼠。

| 验证项 | 结果 |
| --- | --- |
| macOS `cargo test --features ui --lib --tests --offline -- --test-threads=4` | 28 项：1 项 macOS 修饰键、4 项 GUI 生命周期／回退、4 项配置／平台集成、19 项可靠性回归（最后新增的重复关窗测试单独复跑 GUI 测试） |
| macOS `cargo build --features ui --bins --offline` | CLI、GUI 可执行文件构建 |
| Windows `cargo check --target x86_64-pc-windows-msvc --all-targets --features ui --offline` | GUI、CLI、测试和 benchmark 的 Windows 目标编译检查；不代表已链接或运行 Windows EXE |
| `git diff --check` | 检查空白错误 |
| 原生 CLI 进程 SIGINT / SIGTERM | 在真实 TCP 握手等待中取消，分别 45.4ms / 42.0ms 退出，退出码均为 0 |

回归覆盖：

1. 同设备改变 UDP 端口后只向新地址发送；旧会话释放已注入按键，旧 TCP 设置和旧 UDP 移动无效。
2. 双向心跳正常但静止 5.4 秒仍保持控制；服务端持续捕获和客户端持续收到 UDP 都不能掩盖控制连接心跳黑洞，两端在 5.5 秒内释放。
3. 按钮／修饰键按住期间离开、失联、停止、替换连接和关闭键盘；重复清理、释放注入失败与本地输入尾部归属。
4. TCP/UDP 乱序交错时点击位置先应用，随后才执行更新移动；半关闭、部分帧、旧会话、旧剪贴板 epoch、队列溢出和捕获故障。
5. 剪贴板关闭后双方内容不再同步；取消阻塞于网络的半包传输；4MiB 文本传输中按钮释放仍在 1 秒内完成。
6. 重连退避取消、关闭自动重连、服务端重启后自动成功连接、主动停止后不再连接，以及忙碌／旧协议拒绝。
7. GUI 停止处理在 100ms 内更新共享状态；连接握手、正常连接及退避中的取消和回收在 1 秒内完成。清理期间重复关窗不能绕过等待。此项测量状态更新，不是显示器像素呈现时间。
8. 配置全部字段保存恢复、损坏备份、写入失败不覆盖旧配置、UI 开关与语言回退、最后成功连接恢复、单实例唤醒与锁释放。
9. macOS 登录项在临时目录写入、`plutil -lint` 校验和删除；Windows 增加隔离 HKCU 测试适配，由 Windows 原生 CI 执行。本机没有安装测试登录启动项。

macOS 实际 GUI 冒烟使用临时 `.app` 和隔离配置：确认窗口正常渲染，语言即时切换且重启后保留，托盘开关即时生效，关闭托盘后关窗退出，开启托盘后关窗隐藏且进程继续运行。检查结束后测试进程已退出。

隐藏窗口后的系统托盘菜单无法由当前 CUA 自动化接口读取（超时）；托盘“打开／停止／退出”通过 GUI 动作处理与真实 TCP 握手等待的程序化测试覆盖，完整原生菜单点击路径仍待人工确认。

CI 已加入 GUI 构建以及 macOS／Windows 原生测试；本轮没有触发或取得远端 CI 运行结果。尚未完成双机网络与真实键鼠手感、Windows 真机、macOS 11 真机、登录／注销后的实际自启动验收。原生系统剪贴板 API 自身异常阻塞的时长也不能由模拟网络测试保证。本轮不扩展多显示器、跨系统键码映射或第二轮性能改造。
